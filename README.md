Bộ file ứng dụng Quản lý văn bản Đảng - bản sẵn sàng sử dụng.

Cách dùng:
1. Dán toàn bộ nội dung Code.gs vào Apps Script, lưu và triển khai phiên bản mới.
2. Trên GitHub, thay file index.html bằng file index.html trong gói này.
3. Giữ manifest.webmanifest, sw.js, icon-192.png, icon-512.png ở cùng cấp với index.html.
4. Commit changes, mở website và Ctrl + F5.
